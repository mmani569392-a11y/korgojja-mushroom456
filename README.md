# Korgajja Oyster Mushroom Website

A responsive mushroom e-commerce landing page adapted from the original reference layout.

## Structure
- `index.html` — page structure and content
- `css/style.css` — responsive styling
- `js/script.js` — products, filtering, search and cart interactions
- `assets/images/` — supplied hero and five mushroom photos

## Open
Open `index.html` in a modern browser. No build step is required.
